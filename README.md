# 📖 Tentang Project

**Premio** merupakan website marketplace modern yang dirancang untuk menjual berbagai akun dan aplikasi premium secara online.

Website ini memiliki tampilan modern, responsif, dan mudah digunakan sehingga memberikan pengalaman berbelanja yang nyaman bagi pengguna.

Project ini dibuat menggunakan teknologi web modern dengan fokus pada performa, desain antarmuka, dan pengalaman pengguna.

---

# 🎯 Tujuan Project

- Membuat website marketplace modern.
- Menampilkan berbagai produk aplikasi premium.
- Memberikan pengalaman pengguna yang cepat dan responsif.
- Mengimplementasikan teknologi Front-End modern.
- Menghubungkan website dengan database menggunakan Supabase.

# 🚀 Instalasi

Clone repository

```bash
git clone https://github.com/Dijeeee/premio-website
```

Masuk ke project

```bash
cd premio-website
```

Install dependency

```bash
npm install
```

Jalankan project

```bash
npm run dev
```

Build production

```bash
npm run build
```
